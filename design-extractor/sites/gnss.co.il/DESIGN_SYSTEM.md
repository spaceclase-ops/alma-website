# GENESIS (gnss.co.il) — מערכת העיצוב המלאה

מפרט לשחזור אחד לאחד של האתר של ג'נסיס מיתוג ופרסום. נמדד ב-05.10.2026 מהאתר החי בדפדפן Chromium אמיתי (`design-extractor`), בשלושה מסכים: דסקטופ 1440×900, טאבלט 768×1024 ומובייל 390×844. כל מספר כאן נבדק מול הצילומים ומול ה-CSS המקורי (משתני `--e-global-*` של Elementor הם הטוקנים הרשמיים).

> **איך האתר בנוי:** וורדפרס 6.9 + Elementor Pro (קונטיינרים), Swiper, GSAP עם ScrollTrigger ו-MotionPath, Lottie, Animate.css. מעליהם WP Rocket שמעכב את **כל** ה-JavaScript (69 סקריפטים) עד תנועת העכבר או המגע הראשונה. לפני האינטראקציה האתר "קפוא": ה-header לא דביק, הניווט לבן על לבן, אין קרוסלות ואין אנימציות. המפרט מתאר את מה שהגולש רואה **אחרי** האינטראקציה הראשונה.

קבצים נלווים בתיקייה הזו:
- `report.md`, הדוח האוטומטי
- `tokens.json`
- `tailwind-theme.css`
- `screenshots/`: צילום מלא לכל עמוד
- `sections/`: צילום לכל סקשן
- `components/`: כפתורים, hover, header ותפריטים
- `css/`: הגיליונות המקוריים
- `replica-test.html`: בדיקת האמת (פרק 12)

## 1. אופי המותג והשפה העיצובית

**"משרד דיגיטל עם חוצפה":** בטוח בעצמו, צעיר, מצחיק קצת. מדבר בגובה העיניים אבל צועק בגודל.

- **טיפוגרפיה ענקית היא הגיבור.** כותרות של 98–239 פיקסל בפונט גאומטרי עבה (Anomalia), שתופסות את כל רוחב המסך. כמעט כל סקשן נפתח בכותרת ממורכזת בגובה 98px. כותרת היא אלמנט גרפי, לא רק טקסט.
- **שחור-לבן-ענבר.** בסיס לבן נקי, טקסט שחור-פחם (`#212224`), וצבע מבטא אחד: ענבר-חרדל חם (`#F3C052`). אין כחול, אין גרדיאנטים צבעוניים. השחור מגיע גם כסקשנים מלאים (CTA כהה, footer) וכ"סרטים" אלכסוניים.
- **רנדרים תלת-ממדיים שובבים.** אימוג'י צהובים, ידיים מצוירות בסגנון "קליי" (לב, OK, וי, רוק), קפסולת פלסטיק מלאה אייקונים של רשתות חברתיות. כולם על רקע שקוף, לפעמים חותכים את הכותרת.
- **חוסר-סדר מכוון.** קיר ההמלצות כולו מוטה ב-3°-, סרטי טקסט מוטים ב-±2°, תגית מסובבת ב-4°- מתחת ללוגו, כרטיס תיק עבודות מוטה. הכול על גריד מסודר, אבל עם "רעד" של מעצב.
- **תנועה תמידית.** סרטי marquee רצים, מילה מתחלפת בתגית הלוגו, כפתור תפריט שמסתובב, מסלולי "אורביט" של מחלקות, סרטוני סטורי.
- **גיאומטריה כפולה.** כפתור ראשי ושדות פופאפ בצורת **גלולה** (50px). כפתורים משניים וכרטיסי המלצות **מרובעים לגמרי** (0px) עם קו שחור דק. כרטיסים "רכים" (תיק עבודות, מדיה, שבבי מחלקות) ברדיוס 16–32px.

## 3. טיפוגרפיה

### 3.1 הפונט

**Anomalia** בגרסה העברית "Anomalia ML v2 AAA" (פונט מסחרי, AlefAlefAlef ו-Mint Type). מתארח באתר עצמו, בשלושה קבצים בלבד:

```css
@font-face { font-family: "Anomalia"; font-weight: 100; font-display: swap;
  src: url("/wp-content/uploads/2024/08/anomalia-light-aaa.woff2") format("woff2"); }
@font-face { font-family: "Anomalia"; font-weight: 400; font-display: swap;
  src: url("/wp-content/uploads/2024/08/anomalia-regular-aaa.woff2") format("woff2"); }
@font-face { font-family: "Anomalia"; font-weight: 800; font-display: swap;
  src: url("/wp-content/uploads/2024/08/anomalia-bold-aaa.woff2") format("woff2"); }
```

**חשוב:** ב-CSS כתובים משקלים 100–900, אבל יש רק שלושה קבצים. הדפדפן ממפה כך:

| משקל ב-CSS | הקובץ שמוצג |
| --- | --- |
| 100, 300 | **Light** |
| 400, 500 | **Regular** |
| 600, 700, 800 | **Bold** |

כדי להיראות זהה צריך את אותם שלושה קבצים. אם מוסיפים משקלים אמיתיים (300, 700), זה כבר נראה אחרת.

- **רישיון:** הקבצים לא נכנסים ל-git (נשמרו ב-`fonts/`, שמוחרג מ-git). לשחזור מסחרי צריך לקנות רישיון.
- **חלופה חינמית:** Rubik של Google Fonts (שהאתר עצמו מגדיר לכפתורים כברירת מחדל ב-kit), בשלושת המשקלים 300/400/800.

## 12. בדיקת אמת

את `replica-test.html` בניתי **רק מהמסמך הזה**: header, ‏hero, זוג הסרטים, פס הטלפון במובייל ועיגול הנגישות, בלי להעתיק CSS מהמקור. הנכסים המקומיים הם הפונטים מ-`fonts/`, ‏`images/capsule.webp` ו-`brand/logo.svg`. את הצילום וההשוואה עשה `compare.mjs` (בתיקיית הכלי), באותו גודל מסך כמו הצילום המקורי.
