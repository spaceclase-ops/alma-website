# Design Extractor — חילוץ העיצוב המלא של אתר

כלי שפותח דפדפן Chromium אמיתי, טוען אתר חי (או עמוד שנשמר מקומית) ומודד את **כל** העיצוב שלו כפי שהוא מוצג בפועל: צבעים, טיפוגרפיה, ריווחים, רדיוסים, צלליות, נקודות שבירה, קומפוננטות, מצבי hover, אנימציות ופריסת כל סקשן — בדסקטופ, טאבלט ומובייל.

התוצר: דוח קריא, קובצי טוקנים מוכנים לשימוש (CSS / Tailwind v4), צילום מסך לכל עמוד ולכל סקשן, וכל ה-CSS המקורי.

## הרצה

```bash
cd design-extractor
npm install                      # פעם אחת (Playwright)
npx playwright install chromium  # פעם אחת במחשב אישי. בסשן ענן של Claude Code כבר מותקן
node extract.mjs https://www.gnss.co.il
```

התוצאה נכתבת ל-`sites/<domain>/` (לדוגמה `sites/gnss.co.il/`). הכי חשוב לפתוח את `report.md`.

| אפשרות | מה היא עושה |
| --- | --- |
| `--pages 10` | כמה עמודים פנימיים לסרוק מלבד דף הבית (ברירת מחדל 6: קודם התפריט, דוגמה אחת לכל תבנית) |
| `--urls url1,url2` | לסרוק בדיוק את העמודים האלה במקום זחילה אוטומטית |
| `--viewports desktop,mobile` | אילו מסכים לצלם (ברירת מחדל: desktop, tablet, mobile) |
| `--headed --wait 30` | פותח חלון דפדפן גלוי ומחכה 30 שניות בכל עמוד, כדי לעבור ידנית CAPTCHA או חסימת עוגיות |
| `--no-hover` / `--no-sections` | מדלג על צילומי hover או על צילום לכל סקשן (הרצה מהירה יותר) |
| `--extra-ca file.pem` | לסמוך על CA של פרוקסי שמבצע בדיקת TLS (בסשן ענן זה מזוהה אוטומטית) |

אפשר גם להריץ על עמוד שנשמר בדפדפן (Chrome: שמירה בשם ← "דף אינטרנט, שלם"):
`node extract.mjs ./saved/index.html`

## מה נמדד

- **צבעים:** כל צבע שמופיע על המסך, משוקלל לפי שטח, כמות טקסט ומספר אלמנטים. גוונים שהעין לא מבחינה ביניהם (ΔE2000 < 2.3) מאוחדים. התפקידים (primary, background, text, surface, dark, border) מוסקים מאופן השימוש. וידג'טים צפים (וואטסאפ, נגישות) לא נחשבים צבעי מותג.
- **טיפוגרפיה:** משפחות פונטים, מקור (Google Fonts / אחסון עצמי / מערכת), המשקלים שבשימוש, H1–H6 / body / nav / כפתור לכל מסך, סולם גדלים מלא, ובדיקה שהפונט **באמת** נטען (דרך Chrome DevTools).
- **פריסה:** רוחב הקונטיינר, ריפוד אנכי של סקשנים, יחידת הריווח הבסיסית, עמודות ומרווחים. בנוסף, מפת סקשנים לכל עמוד: רקע, overlay, כותרת, עמודות ויישור.
- **קומפוננטות:** Header (כולל בדיקה אם הוא נדבק בגלילה ומה משתנה בו), ניווט, תפריט מובייל פתוח, כפתורים לפי וריאנט עם מצב hover נמדד, קישורים, שדות טופס, כרטיסים, footer, אלמנטים צפים ופופאפים.
- **תנועה:** transitions, keyframes, ספריות (AOS, GSAP, Swiper ועוד) ואנימציות כניסה של Elementor.
- **מקורות:** כל קובצי ה-CSS, משתני העיצוב שהאתר מגדיר (למשל `--e-global-*` של Elementor), ה-HTML המרונדר וטקסט כל עמוד.

## מבנה התוצר

```
sites/<domain>/
  report.md            הדוח המלא (אפשר לקרוא ב-GitHub)
  tokens.json          כל הטוקנים שנמדדו
  tokens.css           משתני CSS ‏(:root + דריסות למובייל/טאבלט)
  tailwind-theme.css   בלוק @theme ל-Tailwind v4, להדבקה ב-globals.css
  palette.svg          לוח הצבעים
  screenshots/<vp>/    צילום מלא + מסך ראשון לכל עמוד
  sections/            תמונה לכל סקשן
  components/          כפתורים, כרטיסים, header, hover לפני/אחרי, תפריט מובייל, פופאפים
  css/                 גיליונות הסגנון המקוריים
  pages/               ה-HTML המרונדר + מתאר טקסט של כל עמוד
  brand/               הלוגו
  data/raw.json        כל המדידות הגולמיות
  fonts/, images/      נשמרים מקומית בלבד (לא נכנסים ל-git: קבצי פונט הם בדרך כלל ברישיון)
```

הרצה חוזרת מחליפה רק את התוצרים שהכלי מייצר. קבצים שנכתבו ידנית באותה תיקייה (למשל `DESIGN_SYSTEM.md`) נשמרים.

## רשת

האתר חייב להיות נגיש מהמכונה שמריצה את הכלי. בסשן ענן של Claude Code צריך להתיר ב-Network access של הסביבה את הדומיין (למשל `gnss.co.il`, `www.gnss.co.il`), וגם את השרתים שמגישים לו פונטים ותמונות (לרוב `fonts.googleapis.com`, `fonts.gstatic.com` ו-CDN). אחרי הרצה, הדוח מציין בדיוק אילו דומיינים נחסמו, כך שקל להשלים. חלופה: להריץ את הכלי במחשב האישי.

## בדיקה עצמית

```bash
node selftest.mjs
```

הבדיקה בונה אתר בדיקה מקומי ב-RTL עם header דביק, תפריט המבורגר, פופאפ, באנר עוגיות, אנימציית AOS, כרטיסים עם hover, טופס, כפתור וואטסאפ צף, CSS ממקור אחר ופונט ווב. היא מריצה עליו את הכלי ובודקת 60 מדידות. לא צריך אינטרנט.
